# PRD：自媒体运营工作台（小红书 · 热点获取）

- 状态：已批准（2026-11-07）
- 作者：PM Bot
- 来源：“给我个人制作一套自媒体运营工作台，先面向小红书平台，做图文，需要有自动获取主题热点信息、图文内容生产、帐号接入，一键发布能力。” —— 本轮试跑只做第一块：自动获取主题热点信息

## 背景与目标

用户是个人小红书图文创作者。每天开始创作前最费时的一步是“今天写什么”，需要知道平台当前在流行什么；现在靠手动刷小红书，效率低、也不及时。

本产品（自媒体运营工作台）最终目标是覆盖“热点发现 → 图文生产 → 账号接入 → 一键发布”全链路。本轮只交付第一块：自动获取主题热点信息，让用户打开工作台就能看到新鲜的小红书主题热点，为选题提供依据。

成功的样子：用户打开热点看板，能看到一份新鲜的小红书主题热点列表，每条含主题名、热度/排名、更新时间，且信息按设定频率自动更新，无需手动查询。

判断指标（可观察）：
- 每次刷新后，热点列表非空，且每条至少含主题名、热度/排名、更新时间。
- 自动刷新按设定频率发生（可通过“更新时间”的变化观察）。

## 目标用户与场景

- 目标用户：个人小红书图文创作者（当前即用户本人，单用户使用）。
- 场景：每天开始创作前，想快速知道“今天小红书在流行什么”，用来决定图文选题方向。

## 非目标

- 图文内容生产（选题、文案、配图）
- 账号接入 / 登录小红书
- 一键发布
- 小红书以外的平台
- 用户未提出的：热点趋势曲线、收藏/标记、通知提醒、数据导出、多用户与登录体系

## 未决问题

- “主题热点”的范围：是小红书平台级热搜榜，还是用户自选赛道/垂类下的热点？推荐：先做平台级热搜榜（热门话题/搜索词），赛道筛选作为下一步。
- 热点条目需要哪些字段？推荐：主题名 + 热度或排名 + 更新时间（最小集）。
- 自动刷新频率？推荐：默认每 1 小时，后续可配置。
- 数据来源方向（合规底线）：官方热点数据 vs 第三方数据平台 vs 公开榜单？推荐：优先合规官方来源；具体实现归技术方案。
- 确认单用户、本人使用，无需登录/多账号体系？推荐：是。
